# LAB_IA_POC_BCRA

Proof of Concept (PoC) no oficial para la integración y consulta de la API pública del Banco Central de la República Argentina (BCRA) con fines educativos.

## AVISO LEGAL Y ATRIBUCIÓN
- **Fuente de datos:** Banco Central de la República Argentina (BCRA).
- **Descargo de responsabilidad:** Este repositorio es un desarrollo independiente con fines de prueba y aprendizaje. No posee afiliación, patrocinio ni aval oficial por parte del Banco Central de la República Argentina.
- **Uso de datos:** Toda la información provista proviene de datos de acceso público bajo la legislación vigente de transparencia.

## Requisitos previos
1. Crear un archivo `.env` basándose en `.env.example`.
2. Configurar el token o credenciales de la API en caso de ser necesario.
